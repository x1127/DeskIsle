REA 对参考 DeskWidget 的静态读取已完成并导出证据；对 DeskIsle 的运行界面观察尝试分别被 macOS 以 `screen-recording-denied`、`accessibility-denied` 拒绝。没有更改系统隐私设置，也没有从其他应用或整屏获取图像。CUA 连接自建应用超时，未用来声明操作验证成功。
